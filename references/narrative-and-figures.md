# 论文叙事、图表组织与讲稿

用于规划或重排生物医药论文汇报。这里记录的是用户已经反复确认的汇报偏好；本次明确指令优先。不要把某篇论文的页数、疾病、算法或样本规模写成通用要求。

## 1. 用论文的结果问题组织主线

先读取摘要、Results小标题、主要图注和Methods中的对应分析，再建立“本节问题—分析对象—证据—回答—剩余问题”对应关系。Results是章节依据，但不必逐字翻译成生硬标题，也不必为每个算法另开一个大章。

- 大章对应一个结果问题；小节对应具体分析任务。名称让听众知道接下来在做什么，如“数据来源与图谱整合”“疾病相关程序评分”“患者分组与外部验证”。不要用“解锁关键洞察”“三大突破”等口号。
- 章节页只有简短标题和一句话承接，不放流程图、公式链、三列卡片或整段摘要。章节页用于转移注意力，不再复述上一节。
- 同一结果中的训练、解释和验证通常连讲，避免每讲一页方法就插一张章节页、再插一张小结。
- 不预设主讲页数。按生物学问题压缩重复说明；不能为了达到目标页数压小图，也不能把主体搬到几十页“备选”后宣称已精简。

可用的承接句：“已有图谱能比较细胞组成，接下来要问，同一种细胞在不同疾病中是否启动了相似的功能程序。”这句指出问题变化，不预告一串软件名称。

## 2. 先讲清比较对象，再讲方法

每幅结果图围绕以下顺序讲，不要求把四步排成四个固定框：

1. 为什么需要这项分析，前一结果还缺什么答案。
2. 比较的是谁：细胞、样本、患者、疾病组还是研究来源；健康组或其他参照在哪里。
3. 图中哪些轴、颜色、点或格子回答这个问题，先看哪一处关键对比。
4. 得到了什么关联或预测结果，不能由此推出什么，下一步为何合理。

方法应在听众需要它时出现。一页可用“输入什么—怎样处理—输出怎样读”的具体例子，不要另起一套与论文脱节的算法教材。详细公式、符号、代码位置放在同页备注或用户要求的学习材料中。合并页面时，缩短上屏文字，保留这些可复查细节。

例如，需要区分“按疾病来源训练的细胞分类器”和“对新患者给出预测的模型”。即使两者都报告F1，也不能把前者的分数称为患者诊断性能。程序权重、程序活动分数、疾病比较系数也应说明各自的统计对象，而不是都写成“活性”。

## 3. 合并小图的依据是同一个生物学问题

满足以下条件才合并：比较对象相容；图例能够独立理解或明确共享；看图顺序自然；按最终投影大小仍能读清必要标记。可以把两条横向散点图上下排，或把同一机制的表达图与验证图并列，不必因为原文使用不同字母就拆页。

不合并的信号：标签缩到需要靠讲者报读；共享色标被裁走；两图需要相反的阅读方向却没有提示；密集点图、网络图或混淆矩阵只能看见轮廓。没有硬性一页约束时，可恢复独立页或增加有来源的局部放大。用户明确要求该组一页时，先提供一页方案并利用已有整图页承接细读；仍有冲突就具体说明，不以本指南擅自增加页面。不要用小图拼贴掩盖页数增加。

例：一张表达热图与一张调控活性热图可以同页比较，但必须说明一个显示基因本身表达，另一个显示靶集合推断活动。两者颜色相近，不代表它们测量同一件事。

## 4. 每节先回看完整证据，再结束小结

用户要求全Figure和小panel展示时，覆盖范围包括正文图、Extended Data和Supplementary Figures，不能只放主图，也不能用讲稿中的图号引用代替真实图片。

推荐顺序是：关键panel细读 → 与本节相关的正文、扩展和补充整图回顾 → 一页本节小结。整图回顾让听众重新看到证据之间的关系；它不能代替对关键panel的实际讲解。

- 一张整图跨多个结果问题时，可以在相应章节重复展示同一完整图，并在原图外注明本节关注的panel；不要抹去其余panel。
- 全图过于密集时，一图一页；必要时另加保留完整标签与图例的分组放大，但分组裁切不能替代完整原图回顾。多个整图同页也必须经过实际阅读检查，不默认“两三张都能装下”。
- 一节有多个相关整图，可连续回顾后再小结，不给每个图都加一张空泛小结。
- 小结以2–3条具体发现为主。方法节可总结输入、输出和用途；结果节总结发现及其解释边界。不要把“完成了分析”“结果很有价值”当作结论。
- 已有讨论总结能够承担最后一节小结时，移动或改标题即可，不重复新增。

小结示例：“同一类细胞的疾病相关程序存在差异；跨研究预测下降提示来源差异仍影响泛化。”只有论文实际支持这两项时才使用；不要把示例直接套入其他论文。

## 5. 维护可核对的图表覆盖台账

在编排时建立台账，交付时以实际PPT包中的图片及页面为准复核。稳定ID是主键，页码是生成结果；合并、插页和移动后重新映射，禁止对全文数字做连续替换。

| 字段 | 要记录的内容 |
|---|---|
| 覆盖单元 | 如F2c、ED4b、S3；无字母的多行图用明确的行或比较对象标识 |
| 原文位置 | PDF版本、物理页、图注、必要的勘误信息 |
| 图像来源 | 原始资产、裁切范围、尺寸、文件哈希 |
| 细读位置 | 实际slide ID及最终页码；只在备注提及不算展示 |
| 完整回顾位置 | 本节的完整图页；标出跨节重复展示 |
| 验收状态 | 文字/坐标/图例/比例尺是否完整，以及实际渲染检查结果 |

不要仅凭文件名或metadata宣称覆盖完成。检查最终PPT中的图片关系和内容；裁切图应能回溯原PDF。源图本身有截尾或错误时先核原文，不能把自己裁掉的数字说成原文局限，也不能猜测补值。

CSV中一行记录一个覆盖单元的一次呈现。同一panel在细读页、跨章节页重复时可以有多行，用源ID、panel ID和slide ID组合区分；页码随最终版本生成。正文整图、扩展整图、补充整图分别核对。只放了所有裁切组而未放完整原图，仍标“整图回顾缺失”。

重要补表按“解决什么问题—关键列是什么—本文在哪里使用”解释。必要时放少量真实行与列并保留出处。提到补表名称不等于已展示关键数据；也不需要为了完整而把几千行塞进PPT。

## 6. 作者介绍回答“这项工作从何而来”

查论文的作者贡献与发表时单位，再用官方团队或机构页面核对研究方向、代表方法和相关论文。保留至少一张用户要求的真实官网截图，注明网页来源；照片不冒充截图，生成图不冒充官网。

作者页宜把身份、研究主线和代表工作连起来，避免只排头像与职称。既往算法可以说明团队积累，但须明确是否用于当前论文。当前网页职务与论文发表时角色分开标注；同名作者或无法核实的职称不补猜。

两页内容重复时可合并为“作者团队与研究方向”，保留可读截图，把完整作者分工与方法边界移入备注。不要因精简删掉此前用户明确要求的研究内容与代表工作。

## 7. 讲稿像讲论文，不像交付说明

备注写成可连续口述的中文：从疑问进入，解释动作与比较，再读出结果和边界。术语首次出现就用普通话解释；数字例子必须明确是教学假设还是论文结果。

不写“本页用于展示”“请读者点击”“此图已经裁切”“我们没有重跑代码”等制作旁白。复现范围和交付限制单列说明；但关系不是因果、验证不是临床部署等科研边界应自然融入讲稿。

合并后逐项清理“上一页、下一页、左图、右图、前两页”等旧指向。用图号、具体对象或“这个例子”衔接；只有实际布局仍对应时才保留方位。备注中的数据、公式、来源不能因合并丢失。

最后的讨论同时写贡献、具体不足和可检验的启发。例如：疾病选择代表性、疾病与来源混杂、采样未覆盖的细胞、候选机制缺少功能验证、外部或前瞻验证不足。启发要与这些不足相连，不泛称“未来可以做更多研究”。全血迁移可以是某篇PBMC研究的提案，必须说明新增细胞与技术差异需要重新验证；它不是所有生物医药论文的必选结论。
